# Contributing

Changes that can affect public records must preserve the separation between discovery,
verification/review and publication.

A new source adapter must:
1. identify the source and evidence type;
2. retain provenance;
3. document whether it is discovery, corroboration or authoritative;
4. add tests;
5. never bypass privacy or publication gates.

Do not add scraped private contact details, unverified residential addresses or unlicensed
images to public output.
